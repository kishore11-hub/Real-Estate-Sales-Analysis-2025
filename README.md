# 🏢 Real Estate Sales Analysis – 2025

## 📌 Project Overview

This project analyzes **real estate sales data for the year 2025** using **Python and Pandas**.
The goal is to uncover **sales trends, city-wise performance, and property-type insights** to support data-driven business decisions.

The dataset is synthetic but designed to closely resemble **real-world real estate transaction data**.

---

## 📊 Dataset Description

* **Time Period:** January 2025 – December 2025
* **Number of Records:** 500
* **Cities Covered:** Mumbai, Delhi, Bengaluru, Chennai, Hyderabad
* **Property Types:** Apartment, Villa, Commercial

### Columns:

| Column Name               | Description                  |
| ------------------------- | ---------------------------- |
| `date`                    | Transaction date             |
| `city`                    | City where property was sold |
| `property_type`           | Type of property             |
| `units_sold`              | Number of units sold         |
| `price_per_unit_lakhs`    | Price per unit (₹ Lakhs)     |
| `total_sales_value_lakhs` | Total sales value (₹ Lakhs)  |
| `month`                   | Extracted month from date    |
| `year`                    | Extracted year from date     |

## 📈 Key Insights

* Identified **top-performing cities** based on total sales value
* Analyzed **monthly sales trends** to detect seasonality
* Compared **property types** to understand revenue contribution
* Commercial properties generated **higher revenue per transaction**
* Apartments showed **higher sales volume**
